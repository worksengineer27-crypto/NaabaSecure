# Messagerie souveraine — Hackathon 226

Messagerie instantanée chiffrée de bout en bout pour l'administration publique,
basée sur le protocole Matrix (Synapse + Element), déployable en une seule
commande via Docker Compose.

## État d'avancement
- Architecture Docker Compose en place (Caddy, PostgreSQL, Synapse, Element)
- Configuration Synapse en cours de durcissement
- Comptes de démonstration configuer
- phase de test sur le web et elementx(sur téléphone) a venir
